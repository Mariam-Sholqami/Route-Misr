# Route Misr

**Live Demo:** [Visit Route Misr](https://route-misr.vercel.app/)

## About The Project

Route Misr is a social media application built with React, TypeScript, and Tailwind CSS.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- HeroUI
- React Router
- TanStack React Query
- React Hook Form
- Zod
- Axios

## Features

- User authentication (sign up and login)
- Create, edit, and delete posts
- Like, comment, reply, and share
- Bookmarks (saved posts)
- Follow and unfollow users
- User profiles with profile and cover photos
- Notifications
- People you may know
- Feed tabs: All and Following (with a photos-only filter)
